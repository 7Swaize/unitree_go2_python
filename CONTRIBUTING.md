# Contributing to Go2-Control

1. Before you start to work, please create an issue first. Before an issue can be worked on, it must be reviewed and given the `approved` tag by an owner.

2. Create a branch with the prefix `go2-$ISSUE_NUMBER$`. All commits **MUST** be made to that branch.

3. Every commit must have the prefix `[#$ISSUE_NUMBER$]`.

4. Create a pull request.
