# Aruco Markers Examples

This folder contains examples for chaining controller functionalities to detect and react to Aruco markers.
These examples are more complex than the others and assume you have already added visible ArUco markers to your scene.
If you haven't, please see the [add_aruco_markers.py](../terrain_generator/add_aruco_markers.py) example.


## What's Here

- [find_markers_sim.py](find_markers_sim.py) — Program showcasing Aruco detection and reaction in the Mujoco Simulator.
- [aruco_helpers.py](aruco_helpers.py) — Aruco marker detection helpers used by the examples.
